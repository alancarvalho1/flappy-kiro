🧪 Manual Testing Guide

  1. Desktop Testing: Open the game at various window sizes (try resizing the browser window)
  2. Tablet Testing: Test on iPad/Android tablet in both portrait and landscape modes
  3. Mobile Testing: Use Chrome DevTools device emulation or test on physical devices
  4. Orientation Testing: Rotate device between portrait and landscape to verify dynamic scaling
  5. Edge Cases: Test at extreme resolutions (very small and very large viewports)
  6. Gameplay: Verify game is playable at all tested resolutions
  7. UI Clarity: Ensure score display and text remain readable at all scales
  8. Performance: Monitor frame rate - should maintain 60 FPS across scales

📊 Responsive Canvas Architecture

Class: ResponsiveCanvasManager

Key Methods:
  • calculateCanvasSize() - Computes display dimensions
  • updateCanvasSize() - Applies new size and updates UI
  • getScale() - Returns current scale factor
  • getDisplayDimensions() - Returns width and height in pixels
  • screenToGameCoordinates() - Maps input coordinates
  • getViewportInfo() - Returns debugging information
  • setupResizeListener() - Handles window resize events
